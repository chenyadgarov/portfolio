# Personal Portfolio Website

A personal portfolio website built to present my background, projects, resume, certificates, and contact information in one organized place.

The goal of this project is to create a clean and professional online presence as a Computer Science graduate, while also practicing core front-end development skills using HTML and CSS.

## Live Demo

🔗 [View Portfolio](https://chenyadgarov.github.io/portfolio/)

## Project Purpose

This portfolio was created as part of my journey into the software development field.  
It is designed to showcase my technical projects, academic background, certificates, and personal development as a junior developer.

The website is still under development and will continue to improve as I add more projects and refine the design.

## Features

- Personal homepage
- Projects page
- Resume page
- Certificates page
- Contact page
- Fixed side navigation
- Multi-page layout using an iframe-based structure
- Responsive layout improvements in progress
- Clean visual design with separate CSS files for different sections

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub Pages

## What I Practiced

While building this project, I practiced:

- Structuring a multi-page website
- Using semantic HTML elements
- Creating reusable page sections
- Designing navigation between pages
- Styling with CSS
- Organizing files and folders
- Deploying a static website with GitHub Pages
- Presenting projects in a professional way
